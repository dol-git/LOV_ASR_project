# Phylogenetic Trees

Canonical v2 IQ-TREE tree files are stored directly in this directory.
`bacterial_*_v2.treefile` and `plant_*_v2.treefile` preserve the four MAFFT strategy
results. The former `bacterial_only/` and `plant_only/` copies contained identical
bytes and were consolidated into these canonical paths.

`comparison/` retains both historical and v2 topology summaries. Their differing
contents and source labels are preserved. Confirm the input tree set before
comparing tables across versions. Node identifiers are specific to their source
tree and reconstruction.
