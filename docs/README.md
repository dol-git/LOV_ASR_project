## Required evidence

Experimental analysis requires raw spectra, recovery traces, measurement
conditions, replicate metadata and fitting provenance. MD requires
construct-to-residue mapping, topology and coordinates, force-field/adduct and
HMR settings, equilibration/restart provenance, production inputs and logs.
These materials remain external. Follow the [analysis guides](../analysis/README.md)
when restoring the original workspace.
